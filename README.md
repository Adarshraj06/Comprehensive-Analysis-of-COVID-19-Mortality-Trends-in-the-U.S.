Comprehensive Analysis of COVID-19 Mortality Trends in the U.S.

This project analyzes COVID-19 mortality data in the United States using Python and Exploratory Data Analysis (EDA) to uncover demographic, temporal, and regional patterns in pandemic deaths. The analysis compares COVID-19 deaths with pneumonia and influenza, identifies peak mortality periods across states, and studies monthly trends in deaths.

📊 Key Insights

Older age groups (especially 75+) experienced the highest mortality

Male mortality was higher than female mortality across most age groups

COVID-19 deaths showed a strong correlation with pneumonia deaths

Different states experienced peak mortality in different months

The pandemic displayed clear wave patterns, with major peaks during winter periods
